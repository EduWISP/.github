## Significato

- **Riquadro arrotondato:** il tablet della scuola.
- **Libro aperto:** l'istruzione, al centro del progetto.
- **Onde di segnale:** la gestione centralizzata e da remoto (lo "WISP" del nome, in omaggio a OpenWISP).

## File

| File | Uso |
|---|---|
| `eduwisp-logo.svg` | Logo orizzontale su sfondo chiaro |
| `eduwisp-logo-dark.svg` | Logo orizzontale su sfondo scuro |
| `eduwisp-mark.svg` | Solo simbolo (avatar, icone, social) |
| `eduwisp-mark-mono.svg` | Simbolo monocromatico (stampa, timbri) |
| `eduwisp-avatar-500.png` | Avatar per GitHub e altri servizi (500×500) |
| `favicon.ico` | Favicon 16/32/64 px |
| `genera-logo.py` | Script che rigenera gli SVG (richiede `fonttools` e il font Cantarell) |

Tutti gli SVG sono vettoriali puri: il testo è convertito in tracciati e non dipende dai font installati.

## Colori

| Nome | HEX | Uso |
|---|---|---|
| Blu EduWISP | `#163E73` | Simbolo, "WISP" |
| Verde acqua | `#2EC4A0` | Segnale, "Edu" su sfondo scuro |
| Verde acqua scuro | `#14866C` | "Edu" su sfondo chiaro (contrasto AA) |
| Bianco | `#FFFFFF` | Pagine del libro |

## Carattere

[Cantarell](https://gitlab.gnome.org/GNOME/cantarell-fonts) Bold, licenza SIL Open Font License 1.1.

## Uso

Non deformare, ruotare o ricolorare il logo con colori diversi da quelli indicati. Lascia attorno al simbolo uno spazio libero pari ad almeno 1/4 della sua larghezza.
