# Sicurezza / Security

## Stato attuale

EduWISP è in fase di progettazione e **non esiste ancora software distribuito**. Sono comunque benvenute segnalazioni su rischi di sicurezza o privacy *nella progettazione*: usa il modello di issue **Privacy e sicurezza**.

## Segnalare una vulnerabilità

Quando ci sarà codice, le vulnerabilità **non vanno segnalate in pubblico**. Usa la funzione **Report a vulnerability** nella scheda *Security* del repository interessato (segnalazione privata di GitHub). Non includere dati personali reali.

Ci impegniamo a confermare la ricezione, valutare il problema e coordinare con chi segnala tempi e modalità di divulgazione.

---

*🇬🇧 EduWISP has no released software yet. Design-level security or privacy concerns are welcome through the "Privacy e sicurezza" issue template. Vulnerabilities must be reported privately via GitHub's "Report a vulnerability" feature in the repository's Security tab, never publicly. Do not include real personal data.*
